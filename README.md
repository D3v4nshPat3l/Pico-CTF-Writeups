# 📌 About

This repository contains my detailed writeups and learning notes for challenges solved on **PicoCTF**.  
The goal of this repository is to document my cybersecurity learning journey, improve problem-solving skills, and build a strong practical understanding of offensive security concepts.

Each writeup includes:

- Challenge Overview
- Enumeration Process
- Vulnerability Analysis
- Exploitation Steps
- Commands Used
- Payloads
- Screenshots (if required)
- Final Flag
